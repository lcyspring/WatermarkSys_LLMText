# 工程文档：系统设计与使用说明

> 项目：面向大语言模型生成文本的水印嵌入与鲁棒检测系统
> 代码根目录：`WatermarkSys_LLMText/`
> 文档根目录：`docs/`

---

## 1. 系统目标与边界

**做什么**：给定同一组提示，生成“无水印”与“含水印”文本，用统计检验判断一段文本是否带有**指定算法、指定配置、指定密钥**的水印证据。

**不做什么**（必须在论文与答辩中明确）：

1. 不判断作者身份；
2. 不判断内容真实性；
3. 不宣称跨模型、跨算法通用；
4. 未检出 ≠ 人类撰写；检出 ≠ 内容真实。

---

## 2. 总体架构

```
提示集(P) ──► 生成层 ──► 水印嵌入层 ──► 文本/ token 存储
                 │            │
                 │            └─ KGWLogitsProcessor（δ=0 时直通）
                 ▼
             检测层 ──► 后处理扰动层 ──► 评估层 ──► 报告 / Web
                          (删词/截断/替换)     (FPR/FNR/AUC/分层)
```

五层职责：

| 层 | 模块 | 关键职责 |
|---|---|---|
| 生成层 | `model_adapter.py` | `ModelAdapter`（真实 HF 模型）/ `SyntheticLM`（机制级离线模拟） |
| 水印嵌入层 | `watermark/kgw.py` | 绿名单划分、logits 偏置 |
| 检测层 | `watermark/kgw.py` + `detect/` | n/g/z/p、状态机、阈值校准 |
| 后处理层 | `postprocess/` | 字符串级与 token 级删词/截断/替换 |
| 评估与展示层 | `eval/`、`db/`、`web/` | 指标、分层、SQLite 血缘、FastAPI 演示 |

## 3. 核心算法口径

### 3.1 绿名单划分

```
seed  = HMAC-SHA256(key, "kgw-v1" || h(4B) || tok_1(8B) || ... || tok_h(8B))
green = 由 seed 驱动的伪随机抽样，从词表 V 中取 ⌊γV⌋ 个互不相同的 token
```

- γ = 0.25，h = 4，PRF = HMAC-SHA256（固定，不允许临场更改）；
- 抽样用拒绝采样实现，复杂度 O(γV) 而非 O(V)，使批量检测可行；
- 同一 (key, 上下文) 恒产生同一绿名单，跨进程可复现。

### 3.2 生成端偏置

```
logits[green] += δ      # δ ∈ {0, 0.5, 1, 2}
```

**δ=0 时函数直接返回原 logits**，不产生任何随机性或数值扰动，是真正的无水印基线。
这一点由 `tests/test_kgw.py::test_delta_zero_is_true_baseline` 断言。

### 3.3 检测统计量

```
n = 有效生成位置数（排除提示前缀、特殊 token、重复 n-gram 位置）
g = 其中落在绿名单的个数
z = (g − γn) / sqrt(n·γ(1−γ))
p = 0.5 · erfc(z / √2)
判定：z ≥ τ  → 检出
```

状态机：

| 状态 | 含义 |
|---|---|
| `completed` | 有效长度足够，已给出 z/p/判定 |
| `insufficient_length` | n < 32，不进入有效判定 |
| `failed` | 计算异常，必须记录而非静默 |
| `config_mismatch` | 保留状态，用于配置一致性校验 |

### 3.4 阈值校准

- 只用负例（δ=0）校准，目标 FPR=1%；
- 取负例 z 的 (1−1%) 分位数，**向上取整到 1e-6**，避免四舍五入导致多算误报；
- 400 条负例的误报步长为 0.25%，必须同时报告 Wilson 95% 置信区间；
- 三个 δ 档共用同一阈值，禁止按结果回调。

## 7. 复现步骤

```bash
cd WatermarkSys_LLMText
python -m pip install -r requirements.txt
python -m pytest tests -q
python scripts/12_run_all.py
```

输出：`docs/reports/` 下 6 份报告 + `outputs/` 下数据与指标。

真实模型：

```bash
$env:HF_ENDPOINT="https://hf-mirror.com"
python scripts/04_generate.py --mode hf --deltas 0,2 --limit 20 --max-new-tokens 128
python scripts/06_detect.py
```

## 8. 已知限制

1. **离线模拟**：`SyntheticLM` 只验证机制与口径，不代表真实语言分布；
2. **CPU 推理**：本机为 CPU 版 torch，真实模型生成速度受限，全量 1200 段需 GPU；
3. **质量指标**：BERTScore / 困惑度需模型与网络，当前仅报告无模型代理指标；
4. **自然文本负例**：真实人类文本的 FPR 需在 W8 用公开语料复测；
5. **攻击面**：已覆盖删词/截断/替换，尚未覆盖回译、语义改写与大模型改写攻击。
