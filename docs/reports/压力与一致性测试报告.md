## 4. 重复 n-gram 屏蔽消融

| 设置 | 指标 | 数值 |
|---|---|---|
| 正常文本 / ngram_block=0 | 平均 z / z | 14.811 |
| 正常文本 / ngram_block=4 | 平均 z / z | 14.811 |
| 复读文本 / ngram_block=0 | 平均 z / z | 26.833 |
| 复读文本 / ngram_block=4 | 平均 z / z | 1.732 |
| 正常文本 / ngram_block=0 | 有效 n | 200.0 |
| 正常文本 / ngram_block=4 | 有效 n | 200.0 |
| 复读文本 / ngram_block=0 | 有效 n | 240 |
| 复读文本 / ngram_block=4 | 有效 n | 1 |
| 复读文本 / ngram_block=4 | 屏蔽位置数 | 239 |

> 正常随机文本几乎不产生重复 4-gram，屏蔽开关对结果无影响；
> 而“复读文本”下若不屏蔽，重复片段会反复计入 n 与 g，导致 z 虚高、
> 把机器复读误判为水印证据。这是默认开启 ngram_block=4 的原因。

## 5. 配置一致性检查

| 配置对比 | hash_a | hash_b | 指纹相同 | hash 不同 |
|---|---|---|---|---|
| delta=0 vs delta=2 | 95070088e683447b | 8ad75129acb818eb | True | True |
| gamma=0.25 vs 0.30 | 8ad75129acb818eb | 8c85d442c32c3563 | False | True |

> 任一参数变化都必须改变 config_hash，否则结论将无法回溯。
> delta 属实验变量，不进入算法指纹（同一水印方案），但必须进入 hash。
