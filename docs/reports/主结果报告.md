## 判读要点

1. delta=0 的判定率即校准后 FPR，应贴近 1%（实测 0.00%）。
2. delta 越大，平均 z 与检出率单调上升，说明偏置机制方向正确。
3. 短文本（32–63 token）的检出率通常最低，这与统计功效随 n 增长一致。
4. 未检出 ≠ 人类撰写：检测只回答“是否检出指定配置的水印证据”。
