## 解读

1. 删词与截断直接减少有效 token 数 n，检测功效随之下降；
2. 截断 25% 时 n 可能跌破 32 的下限，状态会转为 insufficient_length；
3. 替换类扰动保留长度但破坏 n-gram，z 下降幅度应与替换率正相关；
4. 结论边界：以上为机制级模拟下的趋势，真实模型需复测。
