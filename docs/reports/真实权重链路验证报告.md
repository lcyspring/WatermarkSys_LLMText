# 真实权重链路验证报告

> 目的：回答“代码是否只在模拟器上成立”。
> 结论：**Hugging Face 真实权重 + 真实 tokenizer + 真实 logits 的链路已跑通**；
> 主模型 Qwen2.5-0.5B 未跑，原因是**带宽被限速**（见第 2 节实测），不是代码问题。

---

## 1. 计算环境实测

| 项目 | 实测值 |
|---|---|
| torch | `2.9.1+cpu` |
| CUDA 可用 | `False` |
| CPU 线程 | 10 |
| 结论 | 只有 CPU 版 torch，无 GPU 加速 |

## 2. 网络实测（关键证据）

对 `hf-mirror.com` 实测：

| 测试 | 结果 |
|---|---|
| `config.json` | HTTP 307（需跟随重定向） |
| 权重 range 请求 5 MB | HTTP 206，60 秒仅下载 **2.86 MB** |
| 实测吞吐 | **≈ 47.6 KB/s** |
| 平台提示 | “You have used a large amount of egress… downloads will be throttled or blocked” |

带宽推算：Qwen2.5-0.5B 权重约 1 GB ÷ 48 KB/s ≈ **6 小时**，
在“12 点断网”的窗口内不可能完成；这是主模型实验未能执行的真实原因。

## 3. 本次真实权重验证设置

| 项目 | 取值 |
|---|---|
| 模型 | `sshleifer/tiny-gpt2`（102,714 参数，权重约 5 MB） |
| 词表 | 50,257（真实 GPT-2 BPE） |
| 设备 | CPU |
| 提示 | 6 条（取自 `prompts_v1.jsonl`） |
| 生成长度 | 64 token |
| 参数 | γ=0.25，h=4，HMAC-SHA256，ngram_block=4 |
| 检测阈值 | z ≥ 2.7761（沿用负例校准值；z 的定义与词表大小无关，故可直接迁移） |

## 4. 结果

| delta | 样本数 | 平均 z | 判为有水印 |
|---|---|---|---|
| 0（无水印） | 6 | **−0.29** | 0 / 6 |
| 2（强偏置） | 6 | **13.86** | 6 / 6 |

逐条数据：`outputs/hf_smoke_detections.jsonl`。

## 5. 这说明什么、不说明什么

**说明**：

1. `KGWLogitsProcessor` 在真实 `transformers` 模型上可正确注册并生效；
2. 真实 tokenizer 的分词边界、特殊 token、真实词表规模（50,257）下，检测口径正确；
3. δ=0 时 z 回到 0 附近、δ=2 时 z 显著为正，方向与理论一致；
4. 整条 `--mode hf` 路径（加载→编码→带偏置生成→解码→检测）无代码缺陷。

**不说明**：

1. tiny-gpt2 输出无语义，**不能**作为文本质量或检出率的论文结论；
2. 不能替代 Qwen2.5-0.5B 的真实实验（分布不同、token 统计不同）；
3. 6 条样本不构成任何统计结论，仅作链路验证。

## 6. 解除限制后的执行清单

```bash
# 1) 在有带宽/GPU 的机器上准备模型（约 1 GB）
$env:HF_ENDPOINT="https://hf-mirror.com"
python -c "from transformers import AutoTokenizer,AutoModelForCausalLM; AutoTokenizer.from_pretrained('Qwen/Qwen2.5-0.5B-Instruct'); AutoModelForCausalLM.from_pretrained('Qwen/Qwen2.5-0.5B-Instruct')"

# 2) 真实生成（先 20 条小规模，确认耗时）
python scripts/04_generate.py --mode hf --model-id Qwen/Qwen2.5-0.5B-Instruct \
       --deltas 0,0.5,1,2 --limit 20 --max-new-tokens 128 --vocab 151936 --out outputs/hf_qwen.jsonl --fresh

# 3) 检测与评估（注意 --vocab 必须等于真实词表大小）
python scripts/06_detect.py --input outputs/hf_qwen.jsonl --vocab 151936
```

> 注意：`--vocab` 必须与真实 tokenizer 词表一致，否则绿名单划分错误，z 会被系统性稀释。
> 本次 tiny-gpt2 验证即按 50,257 传入，未使用默认的 2,048。
