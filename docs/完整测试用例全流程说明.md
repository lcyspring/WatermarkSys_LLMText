## 4. 单条样本人工复核（关键验证）

自动化脚本可能“一起错”，因此必须能手工核对一条。取 `outputs/detections.jsonl` 中 δ=2 的第一条：

| 字段 | 值 |
|---|---|
| gen_id | `8ad75129acb818eb-P0001` |
| n（有效位置数） | 200 |
| g（绿名单命中数） | 140 |
| 系统输出 z | 14.696938 |
| 系统输出 p | 3.372028826119679e-49 |
| 判定（τ=2.776089） | True |

手工复算：

```
z = (g − 0.25n) / √(n × 0.25 × 0.75)
  = (140 − 50) / √(200 × 0.1875)
  = 90 / 6.1237
  = 14.696938
```

与系统输出**完全一致**，判定 `14.696938 ≥ 2.776089` 为真。

自查命令：

```powershell
$env:PYTHONPATH="src"
python -c "import json,math;rows=[json.loads(l) for l in open('outputs/detections.jsonl',encoding='utf-8')];r=[x for x in rows if x['delta']==2.0 and x['status']=='completed'][0];n,g=r['n'],r['g'];print(r['gen_id'],n,g,round((g-0.25*n)/math.sqrt(n*0.25*0.75),6),r['z'])"
```

两条 z 相同即 PASS。

## 5. 异常与回退

| 异常 | 系统行为 | 处理方式 |
|---|---|---|
| 生成报错 | 记录 `status=failed` 与 `error`，不中断整批 | 查看错误原因后重跑该配置 |
| 有效长度 < 32 | 返回 `insufficient_length`，`decision=null` | 不判“无水印”，改用更长文本 |
| 阈值文件缺失 | 检测脚本明确报错退出 | 先跑 `05_calibrate.py` |
| 词表大小不一致 | z 被系统性稀释（不报错） | 检测 `--vocab` 必须等于生成时词表 |
| 密钥不一致 | z 回到 0 附近 | 确认 `key_id` 与密钥文件 |
| 报告数字与 CSV 不符 | 说明有人工誊抄 | 只信脚本生成，禁止手改数字 |
