## 摘要（骨架，约 400 字）

针对大语言模型生成文本难以溯源的问题，本文设计并实现了一套基于 KGW 绿名单的文本水印嵌入与鲁棒检测系统。
系统以固定参数（γ=0.25、h=4、HMAC-SHA256）在解码阶段对绿名单 token 施加 logit 偏置 δ，
检测端统计有效 token 的绿名单命中数并计算 z 统计量与 p 值，阈值仅由独立负例校准（目标 FPR=1%）。
在 60 条提示、4 档 δ、1,080 个后处理变体上完成实验：δ=1 与 δ=2 的检出率均为 100%，AUC=1.0000；
错误密钥下平均 z 降至 −0.253，验证了密钥特异性；删词 10%/20%/30% 的检出率分别为 95.0%/70.8%/36.7%。
本文明确结论边界：系统只回答“是否检出指定算法、配置与密钥的水印证据”，不用于判断作者身份或内容真实性。

**关键词**：大语言模型；文本水印；绿名单；假设检验；鲁棒检测

## 第 2 章 相关理论与技术基础

### 2.1 自回归生成与采样
温度、top-p、top-k 对分布的影响（用于解释为何温度会改变检出率）。

### 2.2 绿名单水印原理
- 伪随机划分：HMAC(key, 上下文) → 绿名单
- 偏置：绿名单 logit += δ
- 期望命中率 γ；无偏置时 z ~ N(0,1)

### 2.3 假设检验
- H0：文本无水印（命中率 = γ）
- z 统计量、单侧 p 值
- 阈值与 FPR/FNR 权衡

### 2.4 评估指标
Accuracy / Precision / Recall / F1 / FPR / FNR / AUC / TPR@FPR

## 第 4 章 水印嵌入与检测实现

### 4.1 绿名单划分实现
拒绝采样 O(γV)；同一 (key, ctx) 恒定。

### 4.2 生成端偏置实现
`KGWLogitsProcessor`；**δ=0 直通**，构成真基线（有单测断言）。

### 4.3 检测端实现
排除提示前缀、特殊 token、重复 n-gram；n 为有效位置数。

### 4.4 阈值校准实现
负例分位数 + 向上取整 + Wilson 区间；三档共用。

### 4.5 关键工程决策
| 决策 | 理由 |
|---|---|
| δ=0 直通而非加 0 | 避免浮点/随机性污染基线 |
| 检测排除提示前缀 | 提示不是模型生成，计入会稀释信号 |
| 重复 n-gram 屏蔽 | 避免自增强文本虚高 z |
| 阈值向上取整 | 保证实测 FPR 不超过目标 |

## 第 5 章 实验设计与结果分析

### 5.1 实验设置
- 提示集：60 条（学术/技术/新闻/问答 × 中英）
- 参数：γ=0.25，h=4，δ ∈ {0, 0.5, 1, 2}，ngram_block=4，min_tokens=32
- 校准：400 条 δ=0 负例（40 提示 × 10 种子）
- 运行模式：离线机制级模拟（SyntheticLM, V=2048），**真实模型复测待 GPU**

### 5.2 阈值校准结果
| 项目 | 数值 |
|---|---|
| 阈值 | z ≥ 2.7761 |
| 有效负例 | 400 |
| 经验 FPR | 3/400 = 0.75% |
| Wilson 95% CI | [0.26%, 2.18%] |

### 5.3 主结果
| δ | 平均 z | 检出率 | FNR | AUC |
|---|---|---|---|---|
| 0 | 0.12 | 0.00% | — | — |
| 0.5 | 3.503 | 71.67% | 28.33% | 0.9878 |
| 1.0 | 7.234 | 100.00% | 0.00% | 1.0000 |
| 2.0 | 15.086 | 100.00% | 0.00% | 1.0000 |

### 5.4 长度分层
短文本（32–63 token）检出率最低，符合统计功效随 n 增长的理论预期。

### 5.5 鲁棒性（后处理扰动，1,080 变体）
| 扰动 | 10%/75% | 20%/50% | 30%/25% |
|---|---|---|---|
| 删词 | 95.0% | 70.8% | 36.7% |
| 截断 | 100.0% | 99.2% | 89.2% |
| 替换 | 96.7% | 65.0% | 23.3% |

### 5.6 压力与一致性
- 错误密钥：平均 z = −0.253（密钥特异性成立）
- gamma 不一致（0.20/0.25/0.30）：12.719 / 14.811 / 13.131
- 温度 0.7/1.0/1.3 平均 z：19.563 / 14.811 / 11.921
- 任一参数变化均改变 config_hash（血缘可回溯）

### 5.7 质量影响
各 δ 档 distinct-1 ≈ 0.952、repeat-4 = 0、压缩比 ≈ 2.37，表层指标无显著差异；
语义质量需 BERTScore 与人工盲评补充。
