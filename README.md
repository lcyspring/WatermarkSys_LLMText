# WatermarkSys_LLMText

面向大语言模型生成文本的水印嵌入与鲁棒检测系统 —— 本科毕业设计（李春雨，202305567128）。

## 目录约定

```
d:/WatermarkSys_LLMText/
├─ docs/                          # 全部文档（任务书、开题、计划、报告、论文稿）
│  └─ reports/                    # 由 scripts 自动生成的实验报告
├─ WatermarkSys_LLMText/          # 全部代码与可运行产物
│  ├─ src/wm/                     # 核心包
│  ├─ scripts/                    # 00—12 号流程脚本
│  ├─ tests/                      # 48 项单元测试
│  ├─ configs/                    # 配置与密钥样例
│  ├─ data/prompts/               # 提示集（入库）
│  └─ outputs/                    # 运行产物（不入库）
├─ README.md                      # 仓库入口（结构索引与快速开始）
└─ docs/THIRD_PARTY.md             # 第三方资源与许可边界
```

## 一句话说明系统

复现 KGW 绿名单水印：**可控生成 → 水印嵌入 → 统计检测 → 批量后处理 → 指标评估 → 可视化报告**，
所有结论严格限定为“是否检出指定算法、配置与密钥的水印证据”。

## 快速开始

```bash
cd WatermarkSys_LLMText
pip install -r requirements.txt

python -m pytest tests -q          # 48 项单测
python scripts/12_run_all.py       # 一键离线预演：生成→校准→检测→扰动→指标→报告
python scripts/11_web.py           # 演示系统 http://127.0.0.1:8000
```

真实模型实验（需 GPU/权重，联网时执行）：

```bash
python scripts/04_generate.py --mode hf --deltas 0,2 --limit 20 --max-new-tokens 128
```

## 当前结果（离线机制级预演）

| delta | 平均 z | 检出率 | AUC |
|---|---|---|---|
| 0（无水印基线） | 0.12 | 0.00% | - |
| 0.5 | 3.503 | 71.67% | 0.9878 |
| 1.0 | 7.234 | 100.00% | 1.0000 |
| 2.0 | 15.086 | 100.00% | 1.0000 |

- 阈值：z ≥ 2.7761，仅由 400 条负例校准，经验 FPR 3/400 = 0.75%（95% CI [0.26%, 2.18%]）
- 错误密钥下平均 z = −0.253（证明密钥特异性）
- 后处理扰动检出率：删词 10/20/30% → 95.0/70.8/36.7%；截断 75/50/25% → 100/99.2/89.2%；替换 10/20/30% → 96.7/65.0/23.3%

完整数据见 [总报告_离线预演](docs/reports/总报告_离线预演.md)。

真实模型实验已完成两轮：

- 链路验证（`sshleifer/tiny-gpt2`，真实 50,257 词表）：δ=0 平均 z=−0.29（0/6），δ=2 平均 z=13.86（6/6），见 [真实权重链路验证报告](docs/reports/真实权重链路验证报告.md)。
- 主模型实验（`Qwen2.5-0.5B-Instruct`，词表 151,936，CPU）：四档各 8 条看趋势（平均 z 0.389/1.774/4.116/10.283）；扩样 60+60 后，δ=0 误报 **0/60**（最大 z 1.807），δ=2 检出 **60/60**（平均 z 8.577，最小 4.899），见 [真实模型实验报告](docs/reports/真实模型实验报告_Qwen2.5-0.5B.md)。

## 关键约束

- 参数：γ=0.25，h=4，PRF=HMAC-SHA256，δ ∈ {0, 0.5, 1, 2}
- δ=0 为真正无水印基线（生成端完全不修改 logits）
- 阈值只由独立负例确定，三档共用；最低有效长度 32 token
- 未检出 ≠ 人类撰写；检出 ≠ 内容真实
- 密钥不入库，只记录 `key_id`
